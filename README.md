Publish with GitHub Pages
Create a GitHub repository, for example rajesh-portfolio.
Upload index.html to the repository root.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select branch main and folder / (root), then Save.
Wait for GitHub to publish the site. The URL will appear in the Pages settings.
Customise
Replace YOUR-EMAIL@example.com in the contact button.
In each project tile, replace the HTML comment with an image tag, for example: <img src="assets/project-branding.jpg" alt="Brand identity project">
Create an assets folder in the repository and upload your images/videos there.
Edit the text directly in index.html. Colours are defined near the top in the :root CSS block.
